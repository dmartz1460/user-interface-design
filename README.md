## Projects

### [Project 1: Smart Object UI](/Project1)

Design a user interface for a theoretical Smart Object. 

- **Digital**: Assumes this object will integrate a digital display and digital controls.
- **Smart**: Assumes this object will integrate capabilities to sense its usage or environment, and provide features that support to its user.
- **Mock-up**: Inferface is a digital mock-up on a computer screen to showcase its features and simulate its use and behavior. 

Languages Used: 
- HTML
- CSS
- JavaScript
- Svelte
