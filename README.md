## Projects

### [Project 1: Smart Object UI](/Project1)

Design a user interface for a theoretical Smart Object. 

- **Digital**: Assumes this object will integrate a digital display and digital controls.
- **Smart**: Assumes this object will integrate capabilities to sense its usage or environment, and provide features that support its user.
- **Mock-up**: Interface is a digital mock-up on a computer screen to showcase its features and simulate its use and behavior. 

Languages Used: 
- HTML
- CSS
- JavaScript
- Svelte

### [Project 2: UI Redesign](/Project2/)

Redesign an existing interface. There are a variety of reasons that someone may want to take an existing UI and undertake a fundamental redesign. I think these reasons likely fall into 2 major categories: 

- **Usability**: The current UI is not usable (learnable, efficient to operate and with few and reversible errors) or has significant design flaws (too complex, poor use of design principles- layout, color, text hierarchies, ....). 
- **Design Goal Issues**: The current UI is usable, but it has a design goal that has some core flaw.   Perhaps it aims to achieve one set of goals, at the expense of others.

Languages Used: 
- HTML
- CSS
- JavaScript
- Svelte
