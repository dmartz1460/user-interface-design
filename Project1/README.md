# Project 1: Smart Bank UI

## Overview

The idea of this project was to design a User Interface for a theoretical Smart Object. The object I chose was a Smart Bank with the capability to sense and dispense coins, unlike an ordinary piggy bank. The Smart Bank is also capable of tracking its current capacity, count of each type of coin, and small financial goals.
