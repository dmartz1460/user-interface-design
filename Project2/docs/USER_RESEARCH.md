# User Research

This document includes the results of six observational studies where each interviewee was tasked to solve two challenges. Afterward, they were given an survey.

## Challenges

1. Schedule an event in Langsam 520 for the earliest timeslot available. Once it is scheduled, cancel the booking.
2. Schedule an event for 11/01/2026 at 5 p.m. in any available space. The space must be able to be scheduled without providing a sponsoring organization.

## First Interviewee

### Challenge 1

- **1st Attempt**: selected `Events`, searched Langsam 520, attempted to use `Event Forms`
- **2nd Attempt**: searched by `Location`, used `Express Scheduling`, booked 6:30-7pm, confirmed. Went into event details, selected `Cancelled` under the dropdown to cancel the event

### Challenge 2

- **1st Attempt**: User knew not to use the `Event Form`, searched Old Chem as a building.
- **2nd Attempt**: Used `Express Scheduling` on dashboard, booked Langsam 414 at 5pm. Cancelled event

## Second Interviewee

### Challenge 1

- **1st Attempt**: started from browser, searched UC Langsam, launched 25 live through UC website, went to `Locations`, `Availability` in `Search` screen, clicked on room 520, booked room at 6:30 to 7pm. Could not find how to cancel.

### Challenge 2

- **1st Attempt**: Went to `Event Forms`, did not have an `organization`
- **2nd Attempt**: Used `Express Scheduling` on `Dashboard`, booked Langsam 602 at 5:00pm
**Notes**: User did not notice that the date was reset to Oct 29th (current day) instead of the required Nov 2nd.

## Third Interviewee

### Challenge 1

- The user immediately tried using Express Scheduling tile.
- The user tried typing into Express Locations search bar "langsam5".
- Because there was no space (should be "langsam 5"), nothing showed up.
- The user corrected the mistake but realized Langsam 520 was not an option within Express Scheduling.
- The user initially (incorrectly) assumed that Langsam 520 simply wasn't available to be scheduled.
- They then tried typing "langsam 520" in the Search Locations search bar of the Quick Search tile.
- This brought them to the correct page, where they correctly chose a timeslot and entered the Express Scheduling popup window.
- The user did not enter an Event Name (which is not marked as a required field) and was greeted with an Alert popup. They fixed the issue and successfully scheduled the event.
- They then navigated back to the dashboard by clicking the 25Live button in the header. They immediately noticed that the Your Upcoming Events tile was empty and showed no bookings, making them question if the room was actually reserved. After ~5 seconds, the user independently thought to refresh the page, to which the Your Upcoming Events tile updated to show the booking.
- The user struggled to cancel the booking. They navigated back and forth between the dashboard, search areas, event list, and event details pages.
- On their third navigation to the event details page, they found the "Confirmed" dropdown and correctly switched it to "Cancelled", effectively cancelling the booking.
- However, with little feedback, the user assumed the booking did not actually cancel all the way.
- On the dashboard, they noticed (and didn't like) that the event still appeared in the Your Upcoming Events tile, persisting even after refresh.

### Challenge 2

- The user immediately returned to the Express Scheduling tile on the dashboard.
- In one act with no hiccups, they scheduled a room for 11/01/2026 at 5 p.m.

## Sixth Interviewee

### Challenge 1

- The user clicked the Go to Search button on the dashboard and landed on the search page.
- The user was confused by the Select Object dropdown but decided to choose locations. In the second dropdown, they scrolled until they reached Langsam.
- All Langsam rooms appeared. They selected 520 and scheduled the event without issue.
- After about 3 minutes of trying, the user was unable to find how to cancel the booking. They navigated between between the dashboard, search areas, event list, and event details pages. They never noticed the dropdown that says "Confirmed."

### Challenge 2

- The user returned to the search page. The page had switched to Events as the selected object.
- The user again selected Locations from the dropdown.
- They selected the first location, 60 West Charlton. They selected the first room, 106. Upon trying to schedule, a page for the Event Wizard opened.
- Given their previous experience, they new this was incorrect. They pressed Cancel and tried again but got the same result. After a bit of inspecting, I informed the user that this would not work, as this room requires a Sponsoring Organization to book.
- The user then returned to search, searched for Langsam again, and proceeded to book Langsam 520 again without issue, completing the challenge.
- Tester observation: The Event Wizard vs. Express Scheduling confusion may result in some users always booking the same room they're familiar with for convenience, potentially even if there may be better options available.
